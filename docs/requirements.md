# 요구사항 분석 및 시스템 아키텍처 (W02)

> 온디바이스 AI 연계 영유아 실시간 이상행동 감지 및 스마트 돌봄 관제 플랫폼
> (재)충북과학기술혁신원 생활밀착 공공서비스 실증 연계 과제 — 김나희, 임수정

## 1. 시스템 아키텍처 (3계층)

### 온디바이스 AI 단말 (수집) — `simulator/`
- CCTV 현장 단말에서 COCO 17개 관절 좌표 추출 (Edge 처리)
- 프라이버시 보호: 원본 비디오/영상 미전송 (해킹·개인정보 유출 근본 차단)
- 초경량 전송: JSON 메타데이터만 백엔드로 Transmission

### 백엔드 위험 판정 엔진 (분석) — `backend/`
- 복합 위험 판정: 낙상 수직 가속도 계산 + 동적 ROI 침범 상태머신
- 3단계 경보 체계: 주의 / 경고 / 위험
- 초저지연 이벤트 송출: WebSocket 기반 1초 미만 Push

### 웹 관제 클라이언트 (시각화) — `frontend/`
- Canvas 2D 스켈레톤: 수신 관절 좌표 기반 실시간 골격 시각화
- 동적 ROI 드로잉: 마우스 드래그로 위험/관심 구역 자유 설정
- 사고 전후 5초 리플레이: 웹소켓 링버퍼 기반 재구성

## 2. 핵심 기능 요구사항
| 기능 | 세부 정의 |
|------|-----------|
| 프라이버시 보장 | 원본 비디오 미전송, 관절 좌표 메타데이터 전송 |
| 1초 미만 초저지연 | WebSocket 양방향, 골든타임 긴급 팝업·알림음 |
| 동적 ROI 드로잉 | 마우스 다각형 위험구역 지정, 실시간 좌표 저장 |
| 5초 사고 리플레이 | 링버퍼 기반 이상감지 전후 5초 스켈레톤 궤적 |

## 3. 관절 데이터 포맷
- COCO Keypoint 표준 17개 좌표 (x, y) + 신뢰도(confidence)
- 실제 영유아 CCTV 수집 한계 극복 → AI 가상 이상행동 시나리오(낙상·질식) 데이터 생성/활용
- 초당 30프레임 이상 고속 Line 연결 실시간 시각화

## 4. 화면 설계 (와이어프레임)
- 메인 2D 스켈레톤 모니터링 (수신 상태 노출)
- 동적 ROI 드로잉 툴바 (좌표 DB 즉시 반영)
- 비상 긴급 팝업 & 경보 (1초 미만, 적색 점멸 + 경보음)
- GIS 실시간 세부 팝업 (지도상 카메라/이벤트 클릭 → 세부 메타데이터)
